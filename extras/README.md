# extras/ — необязательные дополнения

## legacy-urls.conf.example

Правила nginx для сайта, переехавшего на WordPress с другой CMS: старые адреса
отдают 410 вместо того, чтобы превращаться в тяжёлый поиск по базе.

Подключается копированием в каталог правил сайта:

```
/etc/nginx/wp-autoinstall/ВАШ-ДОМЕН.d/10-legacy.conf
```

Каталог создаётся установщиком и подключается в конфиг сайта директивой
`include`. Файлы оттуда переживают повторный прогон скрипта — он их не трогает.

Тот же файл можно передать при установке: `--extra-conf путь/к/файлу.conf`.
